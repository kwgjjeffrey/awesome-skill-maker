# Development contract

Read docs/skill-authoring.md for the user's established conventions and docs/source-evidence.md for provenance. Source is this Git repository; installed consumers use GitHub release artifacts, never this checkout. Keep task-facing module SKILL.md separate from implementation AGENTS.md. All tools use Python stdlib; Python >=3.9 is an explicit prerequisite. No daemon is needed for this product.

The toolkit in utils/skill_project_toolkit.py owns deterministic scaffolding, structural validation, release packing, verified extraction and managed activation. Module entrypoints are thin wrappers. Distribution is an explicit allowlist in skill-project.json. Never include tests, development AGENTS.md, private config or source evidence in artifacts. State lives outside installed versions. Refuse unmanaged target replacement and Git checkout installation. Release builds require a clean committed tree; manifest binds source commit, bytes and digest. GitHub authentication stays in gh's environment/config, never files in this repository.

Run python3 -m unittest discover -s tests before release. Verify an installed artifact in isolation, scaffolding and building a second project from it. Structural checks are not proof of business behavior. Supported installation platforms are macOS/Linux; Windows activation requires a separately implemented adapter. Do not claim Windows support.
